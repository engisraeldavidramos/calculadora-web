# Calculadora sencilla

Una calculadora web básica hecha solamente con HTML, CSS y JavaScript. No necesita instalar dependencias ni ejecutar un servidor.

## Cómo abrirla en tu computadora

1. Descarga y descomprime `calculadora_web.zip`.
2. Abre la carpeta `calculadora_web`.
3. Haz doble clic en `index.html`; se abrirá en tu navegador.
4. Para editar el proyecto, abre la carpeta desde Visual Studio Code.

## Archivos

- `index.html`: estructura y botones.
- `style.css`: colores, diseño y adaptación a pantallas pequeñas.
- `script.js`: operaciones, estado de la calculadora y teclado.

## Funciones

- Suma, resta, multiplicación y división.
- Números decimales y cambio de signo.
- Borrado completo y borrado del último dígito.
- Operaciones encadenadas, como `5 + 3 ×` (se calcula de izquierda a derecha).
- Mensaje cuando se intenta dividir entre cero.
- Uso con mouse, pantalla táctil o teclado físico.
